# VALORANT META INTEL

Türkçe VALORANT harita meta rehberi: aktif harita havuzu, rol bazlı S-Tier ajanlar, harita stratejileri ve örnek beşli kompozisyonlar.

## Yerelde görüntüleme

`index.html` dosyasını bir tarayıcıda açmanız yeterlidir.

## GitHub Pages ile yayınlama

1. GitHub deposunu oluşturup bu dosyaları yükleyin.
2. Depoda **Settings → Pages** bölümünü açın.
3. **Deploy from a branch** seçip `main` dalı ve `/ (root)` klasörünü yayınlayın.

Canlı Netlify sürümü: https://creative-genie-5504c3.netlify.app/
